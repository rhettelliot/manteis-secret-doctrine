# SDTR — Seven Protocols for Cognitive Sovereignty

Ancient cosmological architecture, reframed as seven operational protocols for secular knowledge workers who feel lost in post-consumerist capitalist society.

## What This Is

Seven operational protocols extracted from deep esoteric source material and translated into clinical, engineering-framed language. The target reader is a knowledge worker who:
- Has a tech/creative job
- Doesn't go to church / isn't religious
- Feels the system eating them
- Needs practical frameworks, not theology

## Source Material

- `source/` — Original public domain texts (acquired from Internet Archive)
- `src/content/` — Seven protocols + two appendices

## Note on Terminology

All original esoteric terminology has been deliberately replaced with operational language. The original terms, authors, and source texts are decoded in Appendix A for those who want the mapping. The operator-facing text contains zero esoteric vocabulary by design.
